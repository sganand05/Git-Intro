# Learning GitHub 🚀

## 📌 Project Overview
**Learning GitHub** is a beginner-friendly project created to understand and practice the fundamentals of **Git** and **GitHub**.  
This repository is used to explore version control concepts, Git commands, and GitHub workflows through hands-on practice.

---

## 🎯 Objectives
- Learn basic Git commands
- Understand how GitHub repositories work
- Practice version control and collaboration
- Gain confidence using GitHub for real-world projects

---

## 🛠️ Topics Covered
- Git initialization (`git init`)
- Cloning repositories
- Staging and committing changes
- Branching and merging
- Pushing and pulling code
- Resolving merge conflicts
- Using `.gitignore`
- Working with GitHub repositories

---

## 🧑‍💻 Technologies Used
- **Git**
- **GitHub**
- **Markdown**
